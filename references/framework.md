# 四层逻辑图 / Four-layer diagrams / 四層の図

## 简体中文

```mermaid
flowchart TD
    A[① 收什么<br/>使用资格、执行服务、保留资源] --> B[② 怎么算<br/>套餐、标准单位、实际消耗]
    B --> C[③ 定多贵<br/>点数费率、人民币采购价]
    C --> D[④ 怎么实施<br/>适用、共享、优惠、生效与过渡]
    D --> E[分别评价每层<br/>成本、价值、竞争、理解和控制、切换负担]
    E --> F[定位变化<br/>范围？单位？单价？适用条件？]
    F --> G[企业应对<br/>按成功完成一笔业务的总成本管理]
```

## English

```mermaid
flowchart TD
    A[1. Charge scope<br/>Entitlements, execution, reserved resources] --> B[2. Meter<br/>Packages, standard units, actual usage]
    B --> C[3. Rate<br/>Credit rates and currency purchase price]
    C --> D[4. Application and transition<br/>Eligibility, sharing, offers, effective dates]
    D --> E[Evaluate each layer<br/>Cost, value, competition, clarity and control, switching burden]
    E --> F[Locate the change<br/>Scope, meter, rate, or conditions?]
    F --> G[Enterprise action<br/>Manage total cost per successful business outcome]
```

## 日本語

```mermaid
flowchart TD
    A[① 課金対象<br/>利用権、実行、確保資源] --> B[② 計量方法<br/>パッケージ、標準単位、実消費]
    B --> C[③ 単価<br/>ポイント料金、通貨での購入価格]
    C --> D[④ 適用と移行<br/>対象、共有、特典、開始と移行]
    D --> E[各層を評価<br/>原価、価値、競争、理解と制御、切替負担]
    E --> F[変更箇所を特定<br/>対象、単位、単価、適用条件？]
    F --> G[企業の対応<br/>業務成功一件当たりの総費用を管理]
```
